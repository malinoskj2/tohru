# Brand

- `dragon.png`: the bar mark, a baby dragon face in three-quarter view with a short snout and one swept horn, in clear palette glass. 512 × 512 with a transparent background.
- `mascot.png`: the full jellybean dragon, Tohru's mascot for the about panel and other menus. 512 × 512 with a transparent background.

Exact prompt and image hash are recorded in `discord-avatar.json`; concept sources are in `docs/discord-avatar-concepts/`. Committing this asset does not update the live bot.
