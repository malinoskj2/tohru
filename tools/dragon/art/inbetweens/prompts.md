# Drawn inbetween generation

Built-in `image_gen.imagegen`, transparent_background=true. Image 1 is neutral cell 165 from legacy-body.webp; Image 2 is ../hover-source.png. Four calls use the following exact prompt with {row} set to 1, 2, 3 and 4. The outputs are row0.png through row3.png.

Production illustration animation inbetweens for the EXACT pastel glass baby dragon. Image1 is the exact starting upright hovering pose for EVERY row. Image2 is a 5-column,4-row sheet of target hover poses. Use ONLY target row {row} of Image2 (count rows from top). Create a 3-column by 5-row animation sheet, EXACTLY15 separate full-body dragons, evenly spaced, one per square cell with large transparent gutters. Each output ROW corresponds to one target dragon from that input row, from left to right. In each output row, column1 is the 25% inbetween from Image1 toward that target, column2 is the 50% inbetween, column3 is the 75% inbetween. Do not include the endpoints. These are genuine drawn cartoon animation inbetweens smoothly repositioning torso, hips, rear feet, tail coil and wings. Change proportions and facing gradually, not suddenly. Preserve EXACT original recognizable small dot eyes, tiny smile, round face, swept peach horns, pearlescent mint belly, lavender wings and tail. Preserve the same large-head short-limbed dragon character, TWO tiny forepaws, TWO small rear feet, TWO wings, ONE tail in each drawing. Never duplicate faces, heads, tails, wings or feet. She is airborne in ALL cells; no floor, no perch, no props, no shadow. Don't rotate or translate the entire original sprite; smoothly articulate the whole body into the target's actual drawn 3D perspective. Horns and tail stay attached. Fixed camera and character size, all drawings fully inside their cells. Closed smile, open dot eyes throughout. Original soft pastel glass illustration, no harsh shading, no melting or ghosting. Pure transparent background, no labels, no grid lines. Column1 should resemble the original pose closely, column3 should resemble the specified target closely. Target row {row}, its five dragons correspond to the five output rows.

The tool does not expose a deterministic seed/model revision. Output layouts were inspected and selections curated in registration.json; source sheets are not blindly consumed as animation order. Sheet 2, cell 5 has a duplicated head and is never selected.
